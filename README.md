# SurA

Markov state model (MSM) analysis of molecular dynamics simulations of SurA, a periplasmic chaperone of Gram-negative bacteria.

## Contents

| File | Description |
|---|---|
| `MSM_SurA.ipynb` | PyEMMA workflow: featurization, dimensionality reduction, clustering, implied timescales and metastable states |

## Requirements

Python 3 with Jupyter and the libraries listed below. Trajectories and
Schrödinger Suite outputs are **not** included in this repository.

```bash
pip install jupyter numpy matplotlib pyemma mdtraj nglview mdshare
```
